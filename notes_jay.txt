###PATH SELECION RULES
1. Longest prefix match
2. Lowest Admin Distance
3. Lowest Metric

Admin distance
Connected = C = 0
Static  = S = 1
EIGRP = D = 90
RIP = R = 120
OSPF = O = 110
ISIS = IS = 115
iBGP = B = 200
eBGP = B = 20

Metric
10.5.20.0/25 [110/10]
