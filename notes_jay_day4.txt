OSI MODEL

1. Physical Layer
Type of data: bits

Voltage: 802.3af, at, bt
Interface: Copper, Fiber, RF
Transmission
 - Full-duplex
 - Half-duplex
 
2. Data-Link Layer
Type of data: ethernet frames
source mac
destination mac

Errors:
	Giants - exceeds the MTU
	CRC - errors in FCS
	Runts - less than 64 bytes
	
3. Network layer
Type of data: Packets
Source IP
Destination IP

4. Transport Layer
Type of data: Segments
Source port
Destination port

TCP (SAW - Sequence Acknowledgement Window length)
UDP (No SAW)
